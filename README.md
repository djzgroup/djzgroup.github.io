# Dejun Zhang Academic Homepage

A self-contained, responsive static website for GitHub Pages. It includes no build step and no external dependencies.

## Publish to `djzgroup.github.io`

1. Download and unzip this folder.
2. Open the repository that currently powers `djzgroup.github.io` on GitHub.
3. Upload the contents of this folder — `index.html` and the `assets` directory — to the repository root, replacing the older website files if desired.
4. Commit the changes. GitHub Pages will publish the update automatically.

## Small updates

- Edit the content directly in `index.html`.
- Styling is in `assets/css/style.css`.
- The Google Scholar button is already linked to the existing profile; update it in `index.html` only if the profile URL changes.
- Update the selected publication list in the `<ol class="pub-list">` section.

The site is plain HTML/CSS/JavaScript, so it works with GitHub Pages without Jekyll, Node.js, or any configuration.
